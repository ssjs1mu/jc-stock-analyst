# Standing rules for every Joshi's Corner report (owner instructions, 30 Oct 2026)

1. **Branding is never compromised.** Tree logo in its original form (`pipeline/branding/tree_logo.png`, gold on black, never recoloured/cropped). Brand name "Joshi's Corner" in Brush Script MT, golden, bold, always at the TOP of the report. (The build runner cannot install Brush Script MT; the embedded Kaushan Script is the look-alike fallback.)
2. **Colour template follows the market mood** (bullish = green family, cautious = crimson/violet family, balanced = blue family) on every report, with a visible mood label. Morning reports take the mood from the expected opening; evening reports from the day's close.
3. **Footer:** never disclose data sources. Only a short disclaimer ("For information only. Not investment advice. Markets carry risk.").
4. **Morning reports are forward looking.** The top states what to expect at the opening (indicative, from global cues; GIFT Nifty is not available). Then events today, stocks to watch, headlines to track, key levels. Yesterday is mentioned only when it changes today's opening (big move, level break).
5. **Prefer 1 page.** Reduce fonts/tables to fit one page; never drop needed information to do it (2 pages is acceptable for the phone version).
6. Phone/social versions keep all information, use tables (not tiles), readable type, no cartoon art; only realistic photos (`pipeline/branding/mood/`).
